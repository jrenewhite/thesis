## Customer Segmentation Dataset

**Origin:**  
- **Author:** Abishek Sudarshan  
- **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/abisheksudarshan/customer-segmentation)  
- **Title:** Customer Segmentation  
- **Year:** 2023

**Description:**  
This dataset is used for segmenting customers into distinct groups based on their behavior and demographics. The data can be utilized to apply machine learning techniques for clustering, classification, and pattern recognition.
