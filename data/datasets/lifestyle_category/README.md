## Half a Million Lifestyle

**Origin:**  
- **Author:** Anthony Therrien  
- **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/anthonytherrien/half-a-million-lifestyle)  
- **Title:** Half a Million Lifestyle  
- **Year:** 2023

**Description:**  
This dataset provides lifestyle-related data, which can be used to analyze and predict various outcomes related to personal health and well-being. It includes features such as gender, age, and lifestyle habits.
