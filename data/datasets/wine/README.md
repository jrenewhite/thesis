## Wine Dataset

**Origin:**  
- **Author:** Brynja  
- **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/brynja/wineuci)  
- **Title:** Wine Dataset (UCI)  
- **Year:** 2023

**Description:**  
This dataset contains chemical analysis results of wines grown in the same region in Italy but derived from three different cultivars. The dataset is often used in machine learning for classification tasks, aiming to determine the cultivar of each wine sample based on its chemical properties.
