## Iris Dataset

**Origin:**  
- **Author:** Fisher, R.A.  
- **Source:** Public Domain  
- **Title:** Iris Dataset  
- **Year:** 1936

**Description:**  
The Iris dataset is a classic dataset in machine learning and statistics, often used for testing algorithms. It contains measurements of iris flowers of three different species and is used to classify them based on their petal and sepal dimensions.
