## Handwritten Digit Recognition (Digits)

**Origin:**  
- **Author:** Bhavik Jikadara  
- **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/bhavikjikadara/handwritten-digit-recognition)  
- **Title:** Handwritten Digit Recognition (Digits)  
- **Year:** 2023

**Description:**  
This dataset contains images of handwritten digits that are often used for training and testing image classification algorithms. The goal is to classify each digit into the correct label.
