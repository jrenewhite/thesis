## Dry Bean Dataset Classification

**Origin:**  
- **Author:** Nima Pourmoradi  
- **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/nimapourmoradi/dry-bean-dataset-classification)  
- **Title:** Dry Bean Dataset Classification  
- **Year:** 2023

**Description:**  
This dataset is used for the classification of different types of dry beans based on their morphological characteristics. It includes various features that describe the shape and structure of the beans.
