## LiDAR Data for Tree Species Classification

**Origin:**  
- **Author:** Mexwell  
- **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/mexwell/lidar-data-for-tree-species-classification)  
- **Title:** LiDAR Data for Tree Species Classification  
- **Year:** 2023

**Description:**  
This dataset includes LiDAR data for classifying tree species. It contains various features derived from the LiDAR point clouds, which are used in machine learning models to predict tree species.
